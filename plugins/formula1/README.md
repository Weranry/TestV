# formula1

该插件用于在墨水屏上展示 F1 **下场比赛**的信息：开赛时间、地点、赛道轮廓图、赛道基本资料、
周末赛程与赛季进度。

## 数据来源

无需 API key：

- **赛程 / 时间 / 地点**：[Jolpica F1 API](https://api.jolpi.ca/ergast/f1/)（Ergast 兼容接口）。
  一次取当前赛季赛历，本地选出「下一站」。
- **赛道轮廓**：[bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) 的 GeoJSON
  轮廓，按等距圆柱投影绘制。这些文件**已随插件打包**在 `assets/tracks/`（23 条赛道，合计
  不到 100 KB），本地读取、零网络依赖，因此赛道图与长度圈数不会因为外网抖动而消失。
  只有映射表里没有的新赛道才走网络兜底（jsDelivr 优先、GitHub 原始地址其次）。

赛程做了进程内 TTL 缓存（10 分钟），赛道轮廓缓存 24 小时，避免预渲染反复请求。

### 新增赛道怎么办

赛历里出现一条本地映射表没有的赛道时，插件会自己找，不需要改代码：

1. **按年份探测**：仓库里新赛道的文件名是「国家码-首办年份」（如 `es-2027`），先按当前年份
   往前探 6 年，命中即用；
2. **目录索引兜底**：按国家码筛出仓库全部候选文件（索引缓存 7 天），用于找回「不是首次
   加入 F1、只是没进映射表」的老赛道；
3. 两条路径都要过「城市名 + 赛道名」相似度门槛，防止把同国的其它赛道错认成新赛道；
4. 命中结果记在进程内，后续请求不再探测。

实在取不到（外网不通、仓库里还没有这条赛道）时，地图区留空、长度圈数省略，**其余信息照常
显示**；失败结果记住 1 小时，避免每张图都为它等超时。

如果希望完全离线、连探测都不要：把对应的 GeoJSON 丢进 `assets/tracks/`，再在
`lib/track_map.py` 的 `CIRCUIT_FILES` 里加一行 `circuitId → 文件名` 即可。

### 文字溢出策略

所有会变长的文本（赛事名、赛道名、地点、站次、节次名）都走同一套兜底：

- **先缩字号**：标题从 32 降到 16（只按 16 的整数倍降），多数长名字在这一步就能放下；
- **再截断**：仍放不下就按字符截断并补 `..`，用二分找「能放下的最长前缀」，绝不顶出画布；
- **各自留预算**：同一行的两段文字（如「赛事名 + 站次」「节次名 + 时间」）先算右侧固定段的
  宽度，左侧只拿剩下的宽度，谁长都不会压到对方。

底部赛程还多一道保险：放不下的行直接不画，而不是硬挤进画布边缘。

## 视图效果

- 顶部：赛事名（红字）、站次与赛季进度条
- 左侧：赛道轮廓图
- 右侧：开赛时间（按插件时区换算）、赛道名、地点、长度与圈数、周末各节时间

支持的尺寸：

- **`hxl`** (384×184)：紧凑版，展示赛道图、开赛时间、赛道名与地点、长度圈数，以及最多 4 行赛程。
- **`h2xl`** (400×300)：宽裕版，赛程可完整列出（含冲刺周末的 5 节），并在顶部显示倒计时。

字号统一为 16 的整数倍（16 / 32），与框架字体规范一致。

调色板建议：`bwr`（赛事名与进度条用红色高亮）。

## 配置参数

| 参数名   | 类型   | 必填 | 默认值 | 说明                                                        |
| :------- | :----- | :--- | :----- | :---------------------------------------------------------- |
| `round`  | string | 否   | `next` | `next` 下一站 / `last` 已结束的最后一站 / 站号整数（如 `18`） |
| `season` | string | 否   | 当前赛季 | 指定赛季年份，如 `2025`                                     |
| `tz`     | string | 否   | 框架默认 | 站次时间的显示时区，如 `8` 或 `Asia/Shanghai`               |

## 快速预览链接

在运行主程序后，可直接点击查看效果：

**hxl 尺寸 (384×184)：**
[http://127.0.0.1:5000/formula1/view/next_race?size=hxl](http://127.0.0.1:5000/formula1/view/next_race?size=hxl)

**h2xl 尺寸 (400×300)：**
[http://127.0.0.1:5000/formula1/view/next_race?size=h2xl](http://127.0.0.1:5000/formula1/view/next_race?size=h2xl)

**指定站次：**
`/formula1/view/next_race?size=h2xl&round=6`（第 6 站）

**JSON 数据：**
[http://127.0.0.1:5000/formula1/json/race](http://127.0.0.1:5000/formula1/json/race)
